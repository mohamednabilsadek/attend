# حضوري — دليل النشر (قاعدة بيانات أونلاين)

الفكرة: **الصفحة** على GitHub Pages، و**قاعدة البيانات** سكربت Google Apps Script يخزّن البيانات في ملف خاص على Google Drive الخاص بك. كل المستخدمين (طلاب/محاضرين/مدير) يتشاركون نفس البيانات.

## الخطوات (حوالي 10 دقائق)

1. افتح https://script.google.com ← **New project**.
2. امسح الكود الموجود والصق محتوى ملف **Code.gs** كاملًا.
3. غيّر السطر `const SETUP_CODE = 'CHANGE-THIS-CODE'` إلى رمز سري خاص بك (يُستخدم مرة واحدة لإنشاء قاعدة البيانات). احفظ المشروع.
4. من القائمة اختر الدالة **authorize** ثم **Run** ووافق على الصلاحيات (Drive).
5. **Deploy ▸ New deployment ▸ Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط Deploy وانسخ الرابط المنتهي بـ `/exec`.
6. افتح `pages/config.json` وضع الرابط مكان `PASTE_WEB_APP_URL_HERE/exec`.
7. ارفع `index.html` و `config.json` إلى مستودع GitHub، ثم فعّل **Settings ▸ Pages** (Branch: main / root).
8. افتح رابط الموقع (https) ← اختر **مدير** ← **إنشاء قاعدة البيانات** ← أدخل بياناتك ورمز الإعداد.
9. من لوحة المدير أضف المحاضرين. الطلاب يسجّلون بأنفسهم من «طالب ← حساب جديد».

## ملاحظات مهمة

- **https ضروري** لتظهر نافذة طلب إذن الكاميرا والموقع (GitHub Pages يوفره).
- **رمز الإعداد سري** — لا تشاركه. وبعد الإنشاء لا يُستخدم إلا لاستعادة نسخة احتياطية.
- **حمّل نسخة احتياطية مشفّرة** من الإعدادات بعد التغييرات المهمة. لا تضع ملف النسخة في مستودع عام.
- عند تعديل `Code.gs` لاحقًا: Deploy ▸ Manage deployments ▸ Edit ▸ New version (يبقى نفس الرابط).
- كل طلب يستغرق نحو 0.5–2 ثانية (طبيعة Apps Script)، وللحسابات المجانية حصص يومية؛ مناسب لمئات الطلاب، وللأعداد الأكبر راجع الحصص.
- تغيير بريد مستخدم يتطلب تعيين كلمة مرور جديدة له (كلمات المرور تُشفَّر باستخدام البريد).
- يمكنك أيضًا فتح الصفحة بدون config.json بالرابط: `index.html?api=<رابط /exec>`.
